# Cockpit

Your device at a glance, in place of the Today view.

![Cockpit](https://muratkurt.github.io/assets/cockpit/banner.png)

## Install

Add `https://muratkurt.github.io/` in Sileo and install **Cockpit**. Needs PreferenceLoader.

## Requirements

- iOS 16 or later
- RootHide or rootless
- CCSupport for the Control Center button on iOS 16–17

## Features

- **Live** — CPU, memory and GPU; battery health, cycles, temperature and power; network speed and heat.
- **Cleanup** — see what can be freed (app caches, temporary files, logs), review it and clean it. Apps are closed first; only a fixed list of folders is touched.
- **Connectivity** — Wi-Fi, Bluetooth, cellular data and Voice & Data mode (5G, LTE, 3G), Personal Hotspot and AirDrop.
- **Actions** — quick respring (open apps keep running), respring, userspace reboot, close apps, refresh icons, copy IP, safe mode.
- **Tweaks** — turn any tweak on or off; reset, back up and restore its settings.
- **Services** — SSH and frida on or off, iOS MCP status.
- **Processes** — the largest by memory, with an end button.
- **Pull down at the top left** — opens Cockpit from the clock's side, as Control Center opens from the right (off by default).
- **Control Center** — a button opens Cockpit as a sheet over Control Center.

12 languages. A switch at the top returns to the stock widgets. Everything else is in **Settings › Cockpit**.

Details and changelog: [package page](https://muratkurt.github.io/depictions/com.muratkurt.cockpit.html).

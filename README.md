# Cockpit

Your device at a glance, in place of the Today view.

![Cockpit](https://muratkurt.github.io/assets/cockpit/banner.png)

## Install

Add `https://muratkurt.github.io/` in Sileo and install **Cockpit**. Needs PreferenceLoader.

## Requirements

- iOS 16 or later
- RootHide or rootless
- CCSupport for the Control Center button on iOS 16–17

## Features

- **Live** — CPU, memory and GPU load; battery health, cycles, temperature and power; network speed and thermal state.
- **Connectivity** — Wi-Fi, Bluetooth with the connected device, cellular data and AirDrop, each with its own switch.
- **Actions** — quick respring (open apps keep running), respring, userspace reboot, refresh icons, copy IP, safe mode.
- **Tweaks** — turn any tweak on or off; it applies on the next respring.
- **Services** — SSH and frida on or off, iOS MCP status.
- **Processes** — the largest by memory, with an end button.
- **Control Center** — a button opens Cockpit as a sheet over Control Center.

A switch at the top returns to the stock widgets. Everything else is in **Settings › Cockpit**.

Details and changelog: [package page](https://muratkurt.github.io/depictions/com.muratkurt.cockpit.html).
